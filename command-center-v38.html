① Market Mode ─ いつ通常株を買っていい？
ATTACK：NQSAR Blue/Green ＋ Breadth≥60% → 最大12枠。
SELECTIVE：Blue/Green ＋ 50%≤Breadth<60% → 新規保有可能総数は最大4。
STOP：Yellow、またはBlue/GreenでもBreadth<50% → 新規0。既存株は個別Exitまで継続。
DEFENSE：NQSAR Red → 通常株を次回寄りで全退避、新規0。
通常個別株の新規保有可能総数は最大4になるSELECTIVEでも、既存が4銘柄超なら強制的に4へ減らしません。自然減のみです。
Red/STOPからの再開：前日終値時点でBlue/Green＋Breadth≥50%なら、翌営業日寄りから新規Entry資格が復活。自動的に買うのではなく、空き枠とeligible候補がある時だけ。FTD・MC57・3日/5日待ちは不要。
② Eligibility ─ そもそも候補に入れる株
Price≥$5、Daily Dollar Volume≥$10M、SMA50>SMA200、Close>SMA200、RS189 percentile≥85、RS63 percentile≥85。
Biotechnology / Pharmaceuticals: Other は通常個別株候補から原則除外。Theme名ではなくIndustryで判定する。
③ Ranking ─ どれを優先して買う？
ATTACKでは次の正式式。
Final = 0.70 × Stock RS189 + 0.30 × strict LOO Peer Theme Score
Theme Scoreは「Theme RS63」「20日Rank Acceleration」「Theme構成銘柄の21EMA上比率」の等加重。候補銘柄自身Xは3成分すべてから除外（Leave-One-Out）し、自己押し上げを防ぐ。複数Themeなら最も高い有効Scoreを採用。

SELECTIVEではTheme加点を外し、RS189中心。
STOP/DEFENSE中に表示する「再開時ウォッチ順位」は売買シグナルではありません。正式ATTACKと同じ70/30式を全eligible銘柄へ計算し、Market Modeが再開した時に何を見るかを準備しているだけです。
④ Entry / Exit ─ 買った後はどうする？
候補は毎営業日更新。空き枠は引け後判定→翌寄り補充。順位低下・Theme低下・Breadth低下・Yellow・Top12落ちだけでは売らない。

初期Stop：終値≤Entry×0.92 → 翌寄り全売却。
部分利確：初めて終値≥Entry×1.24 → 翌寄り25%だけ利確（1回）。
Winner Trail：残り75%は最高終値Peak Close×0.70。Final Stop=max(Entry×0.92, Peak×0.70)。
Red：Portfolio Exitが最優先。
すべて当日終値で判定し、注文は次営業日寄りで執行。PeakはIntraday Highではなく最高終値。
⑤ TQQQ ─ 通常30%とPanic増額
CURRENT30は「常時30%固定」ではなくStage34 hierarchy。30%はnormal baseで、risk lock等により0%や別Exposureになり得る。

Panic候補 M30_TOUCH30_F80_D10
Seed = VIX Close≥23 AND (QQQ Close−SMA50)/ATR14≤−0.5 AND QQQ 10日DD≤−2%
Seed日をage=0としてage≤30の間にQQQ 4H RSIが上から30以下へTOUCH、かつMC57≥20なら翌寄りでF80発動。F80は固定80%ではなく max(CURRENT30 target, 80%)。Active中はMC57<20またはD10で終了。
⑥ RSI30 Panic Reset ─ 通常株とは別物
正式に使う再現可能Variantは RS63_TOP3_RISE30_SIGTOP3。強いThemeのRS63 Top3だった銘柄が、20営業日以内にRSI14≤30を一度付け、その後の初回RSI上昇日に再びTheme内RS63 Top3なら翌寄りEntry。独立Sleeveで1銘柄2.9%、最大4銘柄、同一Theme最大2、20営業日固定保有、同一reset 20営業日cooldown。通常株の−8% Stop / +24% Partial25 / Peak30を流用せず、ナンピン・分割追加なし。MC57・NQSARはHard Gateにしない。
以前の見出し成績 +6.20% / Win72.3% / PF4.71 はNOT REPRODUCEDのため使用しません。代わりに再現できた厳格Variantだけをlive Sleeveへ接続しています。
⑦ Rotation ─ 何に使う？
役割はWHERE（どこが強い/弱いかのContext）。現時点では通常株のHard Gateでも正式Rankingの加点でもない。PIT研究で残ったDistribution警戒などは参考表示できるが、CURRENT_STRENGTH / INTERNAL_LEAD / EARLY_ROTATIONは将来Alphaが十分確認されていないため買い点数にしない。

つまり、WHEN=NQSAR+Breadth / WHAT=正式V38順位 / WHERE=Rotation参考と役割を分離する。
用語集 ─ NQSAR / Breadth / RS / LOO / MC57
NQSAR：通常個別株の市場リスク状態。Blue/Greenは買付可能側、Yellowは新規停止、Redは通常株退避。
Breadth50：通常株UniverseでClose>SMA50の割合。市場の「上昇がどれだけ広がっているか」。
RS189 / RS63：中期/短中期の相対強度Percentile。高いほどUniverse内で相対的に強い。
strict LOO：候補自身をTheme計算から外す方式。自分の強さで自分のTheme点を水増ししない。
MC57：57ETFを使った市場温度系。通常個別株のHard Gateではないが、TQQQ Panic Entry/Exitでは使用。
