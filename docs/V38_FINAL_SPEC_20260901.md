## 3. Normal Stock

### 3.1 Market Mode

- ATTACK: NQSAR Blue/Green and ordinary-stock Breadth50 >= 60%. New/total normal-stock cap 12.
- SELECTIVE: NQSAR Blue/Green and 50% <= Breadth50 < 60%. New-fill cap 4.
- STOP: NQSAR Blue/Green and Breadth50 < 50%, or NQSAR Yellow. No new entries.
- DEFENSE: NQSAR Red. No new entries and all existing Normal Stock positions exit at the next session open.
- Moving from ATTACK to SELECTIVE must never force existing positions from 12 down to 4. Existing positions decay only through normal exits.

### 3.2 Eligibility

- Price >= $5.
- Daily Dollar Volume >= $10M.
- SMA50 > SMA200.
- Close > SMA200.
- RS189 percentile >= 85.
- RS63 percentile >= 85.
- Structural small Clinical Biotech exclusion remains active.

### 3.3 Ranking

ATTACK:
- Final Score = 0.70 * Stock RS189 percentile + 0.30 * selected Peer Theme Score.
- Peer Theme is fine-grained Theme, not broad Sector/Industry.
- Candidate must be excluded from its own Theme return, acceleration and breadth components (strict Leave-One-Out).
- Peer Theme Score = equal-weight Theme RS63 percentile, 20-session rank acceleration percentile, and Theme constituent breadth above 21EMA.
- Multiple Theme memberships: use the highest valid strict-LOO Theme score.
- Missing valid Theme score: neutral 50 only at final score composition.

SELECTIVE:
- Rank by Stock RS189 only; Theme bonus is not used.

### 3.4 Execution and exits

All signals are evaluated from completed closes and execute at the next session open.

- Initial stop: Close <= Entry * 0.92 -> full exit next open.
- First partial profit: first Close >= Entry * 1.24 -> sell 25% next open, once only.
- Remaining 75%: Peak Close trail at Peak * 0.70.
- Final stop = max(Entry * 0.92, Peak Close * 0.70).
- NQSAR Red portfolio exit has priority and executes next open.

Do not exit solely because of:
- rank deterioration,
- Theme deterioration,
- falling outside Top12,
- Breadth threshold deterioration,
- NQSAR Yellow,
- 10SMA break,
- 21EMA Low break,
- biweekly schedule.

### 3.5 Portfolio cap

Normal Stock standalone desired exposure is not itself the portfolio budget.
Before Gross100 allocation, portfolio Normal Stock desired exposure must be capped at 70%:

`normal_stock_portfolio_desired = min(normal_stock_standalone_desired, 0.70)`

The final implementation must not allow Normal Stock allocated exposure above 70%.

### 5.2 Selective TQQQ Fill — FORMALLY ADOPTED

Canonical rule: `SELECTIVE_FILL_NO_ZERO_OVERRIDE`.

This is formally adopted, not merely a candidate.

Purpose: use otherwise-idle Gross100 capacity in favorable ordinary-stock market modes without overriding TQQQ risk locks.

Required semantics:
- Gate uses prior/completed market information only.
- Eligible market condition: NQSAR Blue/Green with ordinary-stock Breadth50 >= 50% (ATTACK or SELECTIVE).
- Normal Stock and RSI Reset allocations are never reduced to create the fill.
- Fill uses only remaining Gross100 capacity.
- Native TQQQ target must be > 0. If the native Stage34 CURRENT30 target is 0, Selective Fill must be 0 and must not override the risk lock.
- Fill may raise actual TQQQ allocation above the native requested target only by consuming otherwise-idle capacity, subject to Gross100 <= 100%.

Evidence anchors:
- Lock-guard audit: run 33483510815 / artifact 9790852808.
- Robustness audit: run 33488546373 / artifact 9792780188.

### 5.3 Panic TQQQ

Canonical Panic rule: `M30_TOUCH30_F80_D10`.

Seed must occur within the last 30 sessions:
- VIX Close >= 23,
- QQQ SMA50 distance <= -0.5 ATR,
- QQQ 10-session drawdown <= -2%.

Trigger:
- after Seed, completed QQQ RTH 4H RSI14 TOUCH30: prior 4H RSI > 30 and current completed 4H RSI <= 30.

Execution:
- signal after the completed 4H bar/session information,
- rebalance at the next session open,
- no same-session-open use of future 4H information.

Panic allocation:
- temporary TQQQ floor = 80%, i.e. max(native CURRENT30 target, 80%) before Gross100 constraints.
- maximum hold = 10 sessions.
- early exit: MC57 < 20 -> next-open exit from Panic overlay.
- NQSAR is not a separate Panic overlay entry gate; NQSAR remains part of the underlying CURRENT30 hierarchy.

4H timing parity audit is PASS.
