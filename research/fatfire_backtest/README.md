# V38 FAT FIRE backtest

Research-only backtest harness for reconstructing V38-style market regimes and testing portfolio policies from 2011 onward without changing the production Command Center.

Goals:
- start capital: JPY 9,000,000
- annual contribution: JPY 1,000,000
- evaluate after-tax outcomes
- combine regime gating, leveraged Nasdaq exposure, and V38-style stock selection
- keep all assumptions explicit and prevent look-ahead bias

This branch is intentionally isolated from production until the research results are validated.
